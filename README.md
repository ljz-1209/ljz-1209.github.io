## Git 核心概念

**分支（Branch）**：从主线（如 main）分出来的一条独立开发线，可以在这条线上修改代码、试验新功能，而不影响主线上其他人正在用的代码。

**合并（Merge）**：把一条分支上的改动整合回主线（或另一条分支），使两条原本分开的开发线汇合成一条。

打个比方：分支就像写文章的草稿副本，你可以在副本上随意改，原稿不受影响；合并就是把副本上定稿的内容誊回原稿。

## 命令行基础

### 目录操作

- `cd <路径>`：切换当前工作目录。`cd ..` 返回上一级，`cd ~` 回到家目录，`cd -` 回到上一次的目录。
- `ls`：列出当前目录内容。`ls -a` 显示隐藏文件，`ls -l` 显示详细信息，`ls -lh` 大小人类可读。
- `mkdir <目录名>`：创建目录。`mkdir -p a/b/c` 可递归创建多层。
- `pwd`：显示当前所在目录的完整路径。

### Git 常用命令

| 命令 | 用途 |
|------|------|
| `git init` | 初始化新仓库 |
| `git status` | 查看工作区和暂存区状态 |
| `git add <文件>` | 添加改动到暂存区，`git add .` 添加全部 |
| `git commit -m "说明"` | 提交暂存区内容到本地仓库 |
| `git log --oneline` | 查看简洁提交历史 |
| `git branch` | 列出本地分支 |
| `git checkout -b <分支名>` | 创建并切换到新分支 |
| `git checkout <分支名>` | 切换到指定分支 |
| `git merge <分支名>` | 把指定分支合并到当前分支 |
| `git remote add origin <地址>` | 关联远程仓库 |
| `git push` | 推送提交到远程 |
| `git pull` | 拉取远程更新并合并 |
| `git clone <地址>` | 克隆远程仓库到本地 |

## 许可证

本项目采用 **MIT 许可证**。

**选择理由**：
- MIT 是最宽松的开源协议之一，允许任何人自由使用、复制、修改、分发和商用。
- 唯一要求是保留版权声明，不强制衍生作品开源。
- 措辞简短，不像 Apache 2.0 需要 NOTICE 文件，也不像 GPL 有传染性。
- 本项目是学习项目，希望代码能被最大范围参考，所以选 MIT。

**已知局限**：MIT 不含专利授权条款，涉及专利敏感技术时可能需要 Apache 2.0。
